I'm building Reviu, a native desktop Git client focused on fast review workflows.

The free version covers local Git: reviewing diffs, staging and restoring changes, commit workflows, and branch/rebase/stash/cherry-pick flows in a keyboard-first UI.

Reviu Pro adds GitHub notifications, repository browsing, pull request review, and issues directly in the app.

I built it because I wanted local Git and GitHub review in one place instead of constantly switching between the CLI, desktop Git tools, and the browser.

It's built in Rust with GPUI.

I'd especially love feedback on the local Git UX, the PR review flow, and pricing.
