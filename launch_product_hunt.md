
## Longer Description

```text
Reviu is a native desktop Git client built for fast review workflows.

The free version covers local Git: reviewing diffs, staging and restoring changes, committing, branching, rebasing, stashing, cherry-picking, and conflict resolution in a keyboard-first UI.

Reviu Pro adds GitHub notifications, repository browsing, pull request review, and issues directly in the app.

I built it because I wanted local Git and GitHub review in one place instead of constantly switching between desktop Git tools, the terminal, and the browser.

Reviu is built with Rust and GPUI.
```
